# VirusPC/coderabbit

本仓是 VirusPC 个人账号下的 [CodeRabbit 中央配置仓库](https://docs.coderabbit.ai/configuration/central-configuration)。根目录的 `.coderabbit.yaml` 会作为基线，自动作用于本账号下**没有**自己 `.coderabbit.yaml` 的仓库（已在探针仓验证，不限于 GitHub Organization）。

改规则请开 PR，不要直推 `main`。仓级覆盖应在目标仓库另写 `.coderabbit.yaml` 并设置 `inheritance: true`，不要整份复制本文件。

公开仓若不足 10 个 star，仍不会自动审查，需要在 PR 上评论 `@coderabbitai review`。

本仓可以长期保留；实验用的探针仓 `VirusPC/coderabbit-config-probe` 可另行删除。
